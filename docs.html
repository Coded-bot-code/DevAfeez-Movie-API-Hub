Platform & Genre Filter

Browse content by streaming platform (Netflix, Prime, etc.), regional catalogue (Bollywood, Hollywood, Asian), or genre keyword.

GET /api/v3/filter
Parameter Type Description
platform Optional One of: netflix prime apple disney hbo hulu paramount peacock bollywood south hollywood asian anime kdrama trending cinema. Regional platforms (bollywood, hollywood, asian, south) pull directly from curated homepage sections — most accurate. Streaming services (netflix, prime, apple…) use keyword search — best-effort.
genre Optional Genre keyword (e.g. action, comedy, horror). Can be combined with platform.
type Optional 0 all (default) · 1 movies · 2 series.
page Optional Page number (default: 1).
perPage Optional Results per page, max 20 (default: 20).
cURL
# Regional section filter (curated, most accurate)
curl -X GET "https://moviemovieapi.devafeez.name.ng/api/v3/filter?platform=bollywood&type=1" \
     -H "Authorization: Bearer YourApiKey"

# Streaming platform filter (keyword-based)
curl -X GET "https://moviemovieapi.devafeez.name.ng/api/v3/filter?platform=netflix" \
     -H "Authorization: Bearer YourApiKey"

# Genre-only filter
curl -X GET "https://moviemovieapi.devafeez.name.ng/api/v3/filter?genre=action&type=2" \
     -H "Authorization: Bearer YourApiKey"
JavaScript — fetch
const response = await fetch(
  "https://moviemovieapi.devafeez.name.ng/api/v3/filter?platform=bollywood&type=1",
  { headers: { Authorization: "Bearer YourApiKey" } }
);
const data = await response.json();
// data.results.items   — normalised content items
// data.results.filter  — applied filter params
// data.results.note    — set when platform uses keyword-search mode
console.log(data.results.items);

Airing Schedule

Daily, weekly, or monthly airing schedule. Anime episodes are sourced from Jikan (MAL) — no auth, no IP blocks, real-time data. Other genres use upstream release-date filtering.

GET /api/v3/schedule

Available Routes

GET /api/v3/schedule Airing schedule by period — daily, weekly, or monthly
GET /api/v3/schedule/popular Top currently-airing anime ranked by MAL score
Parameter Type Description
period Optional daily (default) · weekly · monthly.
date Optional Start date in YYYY-MM-DD format (default: today UTC).
genre Optional Genre to filter. Leave blank or anime to use Jikan/MAL (most accurate). Any other value searches the upstream catalog by genre + release date.
page Optional Page number (default: 1). Pagination applies per Jikan page (25 items/page).
cURL
# Today's anime airing schedule (Jikan/MAL)
curl -X GET "https://moviemovieapi.devafeez.name.ng/api/v3/schedule" \
     -H "Authorization: Bearer YourApiKey"

# Weekly anime schedule starting from a specific date
curl -X GET "https://moviemovieapi.devafeez.name.ng/api/v3/schedule?period=weekly&date=2026-06-15" \
     -H "Authorization: Bearer YourApiKey"

# Monthly schedule filtered to action anime
curl -X GET "https://moviemovieapi.devafeez.name.ng/api/v3/schedule?period=monthly&genre=action" \
     -H "Authorization: Bearer YourApiKey"
JavaScript — fetch
const response = await fetch(
  "https://moviemovieapi.devafeez.name.ng/api/v3/schedule?period=weekly",
  { headers: { Authorization: "Bearer YourApiKey" } }
);
const data = await response.json();
// data.results.schedule      — array of { date, count, items[] }
// data.results.totalEpisodes — total items across all days
// data.results.dateRange     — { from, to }
// data.results.source        — "jikan" or "upstream"
// items[n].broadcastDay      — e.g. "Wednesdays"
// items[n].broadcastTime     — e.g. "22:00"
// items[n].rating            — MAL score (0–10)
for (const day of data.results.schedule) {
  console.log(day.date, '—', day.count, 'items');
  for (const item of day.items) {
    console.log(`  ${item.title} @ ${item.broadcastTime} — score: ${item.rating}`);
  }
}

Anime Catalog

Filters anime and animation content directly from the upstream homepage and trending sections — no separate index needed. Items are matched by section title or metadata containing "anime" or "animation".

GET /api/v3/anime

Available Routes

GET /api/v3/anime Paginated anime catalog filtered from upstream
GET /api/v3/anime/search/:query Keyword search filtered to anime genre only
GET /api/v3/anime/info/:id Full metadata for an anime title with genre validation
GET /api/v3/anime/sources/:id Episode stream sources with anime genre validation
Parameter Type Description
type Optional 0 = all (default) · 1 = movies · 2 = series
genre Optional Client-side genre filter applied to anime results (e.g. action, romance, horror). Matches against genre, title, and corner fields.
perPage Optional Results per page (default: 20, max: 50).
strict Optional true = pure anime feed — only items with corner=Anime, excludes generic animated films. Default: false.
page Optional Page number (default: 1).
cURL
# All anime and animation (series + movies)
curl -X GET "https://moviemovieapi.devafeez.name.ng/api/v3/anime" \
     -H "Authorization: Bearer YourApiKey"

# Anime series only with action genre filter
curl -X GET "https://moviemovieapi.devafeez.name.ng/api/v3/anime?type=2&genre=action" \
     -H "Authorization: Bearer YourApiKey"

# Anime movies only
curl -X GET "https://moviemovieapi.devafeez.name.ng/api/v3/anime?type=1" \
     -H "Authorization: Bearer YourApiKey"

# Page 2, 30 results per page
curl -X GET "https://moviemovieapi.devafeez.name.ng/api/v3/anime?page=2&perPage=30" \
     -H "Authorization: Bearer YourApiKey"
JavaScript — fetch
const response = await fetch(
  "https://moviemovieapi.devafeez.name.ng/api/v3/anime?type=2&genre=action",
  { headers: { Authorization: "Bearer YourApiKey" } }
);

// data.results.items[n].title     — title
// data.results.items[n].thumbnail — cover image URL
// data.results.items[n].rating    — score
// data.results.items[n].genre     — genre string
// data.results.items[n].type      — "series" or "movie"

);
const data = await response.json();
// data.results is a direct array of source objects (NOT data.results.sources)
// data.results[n].quality           — "1080p", "720p", "480p", "360p"
// data.results[n].stream_url        — proxied HLS/MP4 stream URL
// data.results[n].download_url      — proxied download URL

  if (src.browserCompatible && src.requireMemberType === 0) console.log(src.quality, src.stream_url);
}

);

Audio Dubs

Audio dub tracks are returned inline within the Sources response as an audioTracks[] array.

GET /api/v3/sources/{id}

Dubbed versions are treated as separate subjects. The audioTracks[] array tells you which dubbed subjectId values exist — use each one to call /api/v3/sources/{dubSubjectId} to get that language's stream URLs.

audioTracks[] is present in all sources responses but will be an empty array if no dubbed versions exist for the title. Always check audioTracks.length > 0 before using it.

Field Type Description
language string Human-readable language name, e.g. "French"
languageCode string ISO 639-1 code, e.g. "fr"
isOriginal boolean true for the original language, false for dubs.
subjectId string Subject ID for this dubbed version — pass to /api/v3/sources/ to get its streams.
detailPath string Slug for the dubbed subject.
cURL — Get dub streams (2-step) 
# Step 1: Get sources for the original movie (audioTracks[] is included in response)
curl -X GET "https://moviemovieapi.devafeez.name.ng/api/v3/sources/5099284245269335848" \
     -H "Authorization: Bearer YourApiKey"

# Response includes audioTracks[]:
# { "language": "French", "isOriginal": false, "subjectId": "5099284245269335849", ... }

# Step 2: Get the French dub streams using that subjectId
curl -X GET "https://moviemovieapi.devafeez.name.ng/api/v3/sources/5099284245269335849" \
     -H "Authorization: Bearer YourApiKey"

// Get download sources
async function getDownloadSources(movieId, season, episode) {
  let url = `https://moviemovieapi.devafeez.name.ng/api/v3/sources/${movieId}`;
  if (season) {
    url += `?season=${season}`;
    if (episode) url += `&episode=${episode}`;
